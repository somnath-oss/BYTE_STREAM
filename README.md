# BYTE_STREAM

A simple Java project that demonstrates **object serialization and deserialization** using file streams. This project is helpful for understanding how to save object state to a file and retrieve it later.

---

## 📌 Features

- ✅ Object serialization (convert object to byte stream)
- ✅ Object deserialization (read object from byte stream)
- ✅ dynamic deserialize
- ✅ serilization version id
- ✅ File-based persistence in Java
- ✅ Little bit error handling part
- ✅ Clear and beginner-friendly code structure
